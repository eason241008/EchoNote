# EchoNote 声译使用指南

本文对应 EchoNote 1.0.1（WhisperKit large-v3 版本），介绍安装、首次配置、日常课堂录音、字幕浮窗、连续课程、历史资料、数据管理和常见故障处理。

> EchoNote 只会在你明确点击“开始录音”后使用麦克风。录课前请取得必要同意，并遵守学校规定和当地法律。

## 1. 运行要求

- macOS 15.0 Sequoia 或更高版本。
- Apple Silicon Mac；WhisperKit large-v3 针对 Apple 芯片运行。
- 至少预留 2 GB 空间用于模型下载、解压和验证。
- 课堂录音会持续占用磁盘空间，长课前请另外确认剩余容量。
- 首次下载 WhisperKit 模型、Apple 翻译语言包或同步在线课表时需要网络。

## 2. 安装

### 使用 DMG 安装（推荐）

1. 打开 `EchoNote-1.0.1-macOS-arm64.dmg`。
2. 将 `EchoNote.app` 拖到同一窗口中的 `Applications` 快捷方式。
3. 等待复制完成后推出 `EchoNote 1.0.1` 磁盘映像。
4. 前往“应用程序”，在 Finder 中右键 EchoNote，选择“打开”。

### 使用 ZIP 安装

1. 解压 `EchoNote-1.0.1-macOS-arm64.zip`。
2. 将 `EchoNote.app` 拖入“应用程序”文件夹。
3. 第一次打开时，建议在 Finder 中右键 EchoNote，选择“打开”。
4. 如果 macOS 因为应用未经公证而拒绝打开，请从源码自行构建，或者使用经过 Developer ID 签名和公证的发行版本。当前仓库生成的是本地 ad-hoc 签名包。

### 从源码构建

```bash
git clone https://github.com/eason241008/EchoNote.git
cd EchoNote
swift package resolve
swift test
swift build-app.swift
open dist/EchoNote.app
```

构建脚本会生成：

- `dist/EchoNote.app`
- `dist/EchoNote-1.0.1-macOS-arm64.zip`
- `dist/EchoNote-1.0.1-macOS-arm64.dmg`

## 3. 第一次打开后的配置顺序

推荐按以下顺序设置，能够最清楚地判断哪一步尚未就绪。

### 3.1 安装 WhisperKit large-v3

1. 打开左侧“偏好设置”。
2. 找到“本地英文转写模型”。
3. 点击“下载并验证模型”。
4. 等待状态依次经过“下载中”“正在验证”“正在加载”。
5. 只有 Core ML 模型实际加载和预热成功后，状态才会变成“已就绪”。

模型约 626 MB，默认保存在：

```text
~/Library/Application Support/EchoNote/Models/
```

下载过程中不要强制退出应用。以后启动 EchoNote 时，主界面会先出现，模型会在后台继续加载；模型就绪前“开始录音”按钮保持不可用。

### 3.2 允许麦克风权限

1. 进入“课堂录音”。
2. 选择或准备一节课，让应用执行录音前检查。
3. macOS 弹出权限窗口时选择“允许”。

如果之前选择了拒绝：

1. 打开“系统设置”。
2. 进入“隐私与安全性” → “麦克风”。
3. 为 EchoNote 打开权限。
4. 完全退出并重新打开 EchoNote。

### 3.3 准备本地中文翻译

中文翻译使用 macOS 自带的 Translation 框架，不需要 API Key，也不需要配置云端服务。

- 英文语音先由 WhisperKit large-v3 在本地转写。
- 最终英文字幕再交给 macOS 本地语言模型翻译为简体中文。
- 第一次使用时，系统可能需要下载英语和简体中文语言资源。
- 翻译不可用时，英文转写和录音仍会继续。

### 3.4 导入或订阅课表

有两种方式：

1. 在“我的课表”点击“导入课表”，选择本地 `.ics` 文件。
2. 在“偏好设置” → “课表订阅”粘贴 HTTP/HTTPS ICS 地址，点击“保存并同步”。

在线同步失败时，应用会继续显示上次成功保存的课表。订阅地址可能包含私人令牌，请不要把它提交到 Git 或发送给他人。

### 3.5 确认录音规则

首次录音前，在“课堂录音”页面阅读提示并点击“我已了解并同意”。这只是确认你理解录音责任，并不会自动开始录音。

## 4. 开始一节课的记录

### 当前时间正在上课

1. 打开“课堂录音”。
2. 应用会根据当前时间显示可记录的课表课程。
3. 点击“准备本节课”。
4. 等待顶部状态确认：
   - 麦克风权限正常；
   - 输入设备可用；
   - 本地模型已就绪；
   - 存储空间可用。
5. 点击“开始录音”。

记录名由课表自动生成，例如：

```text
第2周 · 90016 · Tutorial1
```

你不需要手动填写每一节课的记录名称。

### 提前选择另一节课

1. 打开“我的课表”。
2. 使用左右箭头切换周次。
3. 点击希望记录的课程块。
4. 应用会回到课堂录音准备流程。

系统默认允许在课程开始前 15 分钟进行准备，并在课程结束后的五分钟宽限期内识别该课程。

## 5. 录音期间的控制

### 暂停和继续

- 点击“暂停”会暂停麦克风采集。
- 点击“继续”恢复当前记录。
- 即使处于暂停状态，课后五分钟自动结束计时仍然有效。

### 手动停止

点击“停止”会完成当前记录、关闭音频流并开始收尾工作。停止后不要立刻强制退出，让剩余字幕、翻译和文件校验正常结束。

### 下课后自动停止

课表课程会在最后一节连续课程结束五分钟后自动停止。页面会显示预计结束时间。

### 两门连续课程

如果下一门课在当前课程结束后五分钟内开始：

- 麦克风和音频引擎保持运行，中间不会重新启动。
- 到下一门课开始时间时自动切换保存目标。
- 每门课仍然拥有独立的课程记录、音频文件、实时字幕、翻译和课后校对稿。
- 课程切换时会根据课程 ID 分配音频帧，避免边界声音进入错误记录。
- 如果第一门课处于暂停状态，进入下一门课后仍保持暂停，需要手动点击“继续”。

如果两门课之间间隔超过五分钟，第一门课会在宽限期结束时正常停止，下一门课需要重新准备并开始。

## 6. 实时字幕和浮窗

开始录音后，字幕浮窗会自动出现。

### 显示语言

在“实时字幕”页面可选择：

- 中英双语
- 仅英文
- 仅中文

如果选择“仅中文”但本地翻译尚未就绪，可能暂时只看到等待提示；英文原稿仍会继续保存。

### 字幕位置

- “普通浮窗”：可调整大小和位置，适合放在讲义或浏览器旁边。
- “灵动岛式”：固定在屏幕顶部中央、靠近 Mac 刘海。它是视觉上的灵动岛布局，并不是真正嵌入硬件刘海，因为 macOS 没有相应公开接口。

### 文字和背景

“实时字幕”页面可以调整：

- 字幕字号
- 背景透明度

设置会保存在本机，下次打开继续使用。

### 隐藏与关闭

浮窗右上角有两个按钮：

- `−`：临时隐藏现有浮窗。
- `×`：关闭并释放当前浮窗窗口。

两种情况都不会停止录音，也不会删除字幕。需要恢复时，在“实时字幕”页面点击“重新显示字幕浮窗”。

### 浏览历史字幕

- 当滚动位置位于最底部时，新字幕会自动跟随。
- 当你向上翻阅旧内容时，新字幕不会强制把页面拉回底部。
- 返回底部后，后续字幕会恢复自动跟随。
- 浮窗始终优先跟随最新字幕，主应用中的历史记录区则尊重你的阅读位置。

实时段落最多包含两句话，避免一条字幕无限增长。

## 7. 翻译行为

- 翻译只处理已经完成的英文字幕，不处理原始音频。
- 小批次会快速送入本地 Translation 框架，以降低等待延迟。
- 中文翻译与对应英文修订版本保持关联。
- 翻译暂时失败时不会用“翻译”占位文本冒充结果，也不会阻止英文字幕。
- Apple 语言资源恢复可用后，后续字幕会继续翻译。

## 8. 课程资料

打开“课程资料”后，应用才会加载并建立历史课程搜索索引，因此不会拖慢主窗口冷启动。

### 查找记录

- 左侧显示历史课程、完成状态、字幕数和翻译数。
- 搜索框可以查找字幕、翻译、笔记和书签内容。
- 选择一门课后，可以按时间查看实时原稿和中文翻译。

### 课后整课校对稿

课程结束后，EchoNote 会在后台重新处理完整课堂音频，生成一份独立的课后校对稿。

- 它不会覆盖实时字幕原稿。
- 每次生成都会作为单独版本保存。
- 录音期间课后任务会暂停，避免与实时 large-v3 推理争抢资源。
- 在“课程资料”中展开“课后整课校对稿”即可查看。

### 导出

选择一门课程，点击“导出”，可选择：

- Markdown (`.md`)
- SRT 字幕 (`.srt`)
- JSON (`.json`)
- PDF (`.pdf`)

导出时由你选择保存位置。导出的文件可能包含课堂内容，请谨慎分享。

### 删除

点击“删除”并确认后，会删除该课程的数据库记录和本地音频文件。这个操作不可撤销，建议先完成需要的导出。

## 9. 存储和隐私

默认数据目录：

```text
~/Library/Application Support/EchoNote/
```

其中包含：

- `Models/`：WhisperKit 模型。
- `Sessions/`：各节课的原始音频、清单和课后校对稿。
- `lectures.sqlite`：课程、字幕修订、翻译和搜索数据。

在“偏好设置” → “存储与保留”中：

- 可以查看应用数据占用。
- 可以设置原始音频保留天数，范围为 0–365 天。
- 可以点击“在 Finder 中显示”检查数据目录。

默认保留 30 天。设置为 0 表示录音完成后可以立即进入清理范围，不代表正在录音时删除文件。

隐私边界：

- 音频采集和 WhisperKit 英文转写在本机运行。
- 中文翻译使用 macOS 本地语言模型。
- EchoNote 不包含分析或遥测客户端。
- 只有课表同步会访问你提供的 ICS 地址。

## 10. 常见问题

### “The microphone audio engine could not start”

EchoNote 会先重试当前选择的输入设备，再自动尝试系统默认麦克风。若仍失败：

1. 在“系统设置” → “声音” → “输入”确认设备存在且输入电平会变化。
2. 如果使用 AirPods 或蓝牙耳机，等待连接完全稳定后再次开始。
3. 临时把系统输入切换到 Mac 内建麦克风。
4. 关闭正在独占或频繁切换麦克风的会议、录音软件。
5. 检查“隐私与安全性” → “麦克风”中的 EchoNote 权限。
6. 完全退出 EchoNote，再重新打开。

### 模型一直显示未就绪

1. 打开“偏好设置”。
2. 查看状态是下载失败、验证失败还是加载失败。
3. 确认至少有 2 GB 可用空间。
4. 点击“重新验证”。
5. 仍失败时删除模型并重新下载。

不要手动只复制部分 `.mlmodelc` 文件；EchoNote 会检查配置文件和三个核心 Core ML 模型是否完整，并在实际预热成功后才允许录音。

### 有英文字幕但没有中文

1. 确认 macOS 15 的英语和简体中文翻译资源可用。
2. 保持应用打开，等待系统完成首次语言资源准备。
3. 在“实时字幕”确认没有选择“仅英文”。
4. 录音可以继续；翻译失败不会影响英文原稿。

### 浮窗不见了

打开“实时字幕”，点击“重新显示字幕浮窗”。开始下一次录音时浮窗也会自动出现。

### 打开应用需要很久

当前版本会先显示界面，再加载 large-v3；历史课程和磁盘占用也会按需或在后台读取。如果界面长时间完全没有出现，请先检查是否误开了旧版 EchoNote，并确认 `/Applications/EchoNote.app` 是最新构建。

### 课程名称或周次不正确

EchoNote 根据 ICS 中的课程代码、activity、UID 和重复课程顺序生成名称。检查原始课表是否包含正确的课程代码、类型和时区；修改课表后重新导入或同步。

## 11. 安全退出建议

- 正在录音时优先点击“停止”，等待状态变为“录音完成”后再退出。
- 不要在 Finder 中直接删除正在写入的 `Sessions` 文件夹。
- 如果应用或系统意外退出，下次启动会把未正常结束的录音标记为中断，避免误显示为仍在录音。
- 字幕浮窗的隐藏或关闭按钮不会停止麦克风；真正停止录音必须使用“课堂录音”页面的“停止”按钮，或等待自动结束。
